## FREEDOM PLAN 的核心卖点：免费更换 IP

FREEDOM PLAN 最容易被记住的功能，是**每两周可以免费更换一次 IP**，一年最多可以免费更换 26 个 IP。

这项功能适合以下几类场景：

- 需要定期更换服务器公网 IP 的测试环境；
- 某个 IP 出现访问异常，需要更换地址排查问题；
- 部署多个小型项目，希望降低单个 IP 长期使用带来的影响；
- 需要把服务器作为独立开发、测试或远程服务节点使用；
- 经常重装系统、调整服务，想保留更换 IP 的操作空间。

不过，免费更换 IP 不等于可以无限次更换，也不等于每次都能得到某个特定地区或特定运营商的 IP。官方公开信息只确认了更换周期和年度次数，**没有承诺每次更换后的 IP 都具备相同的网络质量、解锁能力或访问结果**。

这点很关键。很多人看到“免费换 IP”就把它理解成“IP 出问题可以随时解决”，实际并不是这样。更准确的理解是：它给了你一个有限的地址调整额度，方便处理部分 IP 相关问题，但不能替代线路选择、服务合规和日常运维。

## 它适合做什么？

### 个人博客和轻量网站

2 GB 内存足以支撑 WordPress、小型博客、文档站、个人主页或轻量级 API 服务。40 GB RAID-10 硬盘可以存放网站程序、日志和一定数量的媒体文件，2 TB 月流量对低访问量项目也比较宽裕。

但如果网站包含大量图片、视频或下载文件，40 GB 很快就会变紧。VPS 不是对象存储，也不是 CDN。把大量静态文件长期塞在服务器里，容易同时受到硬盘容量、流量和备份空间的限制。

### 开发和测试环境

FREEDOM PLAN 的 2 核 CPU 和 2 GB 内存适合运行：

- Linux 开发环境；
- 小型数据库；
- Web 应用测试；
- CI/CD 的轻量任务；
- Docker 容器；
- 私有 Git 服务；
- 监控、日志和自动化脚本。

搬瓦工官方说明其 VPS 采用 KVM 虚拟化，提供 KiwiVM 控制面板，支持开关机、重装系统、紧急控制台、反向 DNS、快照、数据统计和机房迁移等管理功能。

这里有一个容易被忽略的前提：这是**自管理 VPS**。搬瓦工负责底层主机和网络，但不会替你安装应用、配置网站、排查程序报错或恢复应用数据。官方服务条款明确要求用户具备自行管理 Linux 服务器的能力。

### 需要一定流量额度的个人项目

每月 2 TB 流量比很多基础型 VPS 更宽裕。如果只是访问量不大的博客、接口、后台工具或文件同步服务，通常比 500 GB、1 TB 流量的低配方案更从容。

但“2 TB 流量”并不等于不限速下载。实际体验还会受到访问来源、网络路径、对端服务器、TCP 连接、系统配置和服务商策略影响。端口标称 2.5 Gbps，也不能简单理解成任何时间都能跑满 2.5 Gbps。

## 购买前需要检查的几个限制

### 1. 先确认库存和最终价格

限量套餐不是长期固定销售的标准产品。即使某个页面仍然能看到套餐名称，也可能暂时缺货，或者在结账时显示不同的计费周期和价格。

### 2. 注意 CPU 使用规则

搬瓦工服务条款对不同套餐设有 CPU 公平使用限制。条款中将 FREEDOM PLAN 的长期平均 CPU 使用上限列为 **30% of 1 core**；短时间内可以使用更多资源，但如果一小时平均负载持续超过限制，系统可能自动限制可用 CPU 周期。

这意味着“2 cores”不应被理解为可以长期满载使用两颗物理核心。运行轻量网站、开发环境和低并发服务通常问题不大；如果要长时间编译、视频转码、批量计算或运行高 CPU 任务，就应该查看更合适的方案。

### 3. 退款有条件

官方条款显示，新订单通常需要在下单后 30 天内申请退款，同时还要满足账户状态正常、流量使用低于月度额度的 10%、IP 未被列入黑名单且没有违反服务条款等条件。退款会终止相关服务，并删除对应数据、快照和备份。

所以不要把退款政策当成长期试用。准备购买前，应先确认系统版本、项目需求、流量规模和部署方式。

### 4. 免费快照不等于完整备份

FREEDOM PLAN 页面列出了免费自动备份和免费快照，但服务条款仍建议用户自行建立备份方案。

重要数据最好至少保留一份独立于 VPS 的备份。服务器快照主要方便回滚和快速恢复，并不能替代异地备份，也不应该成为唯一的数据保护手段。
